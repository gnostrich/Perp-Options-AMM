PROOF NOTES (routes I have already checked by hand; use them or better ones).
* `AR p 0 = qR p * WR p` and `AL p 0 = qL p * WL p` reduce via `uArg _ _ 0 = 0` (`Real.zero_rpow`,
  `a ≠ 0`) and `ibeta_zero`; then `atm_wings_meet` is the algebra
  `WL·WR/(WR+WL) = (1 - WL/(WR+WL))·WL`.
* `G1 < 1` because the base `1 + (1/sL)^a > 1` and the exponent `-(γ+1)/a < 0`.
* `AL_glue` is definitional: at `m = 1` the bracket is `I1 - I1 - 0`.
* Layer 2 skeleton. Write `bracket m = tail p (sL p) m - I1 p - G1 p * (1 - m)`. From
  `TailRep.lower` with `m' = 1` and `kern p (sL p) 1 = G1 p`, `bracket m ≥ 0` for `m ≤ 1`; more
  generally for `m ≤ m' ≤ 1`, `bracket m - bracket m' ≥ (m'-m)(kern p (sL p) m' - G1 p) ≥ 0`
  (kernel antitone, `kern 1 = G1`), and by `TailRep.upper`,
  `bracket m - bracket m' ≤ (m'-m)(kern p (sL p) m - G1 p) ≤ (m'-m)(1 - G1 p)`; dividing by
  `1 - G1 p > 0` and multiplying by `qL ∈ [0,1]` gives `ALm_antitone` and `ALm_lipschitz` (both
  also hold across the `1 ≤ m` cutoff, where `ALm = 0`). Then `CALL_antitone` is three cases:
  `0 ≤ k ≤ k'` (right wing antitone); `k ≤ k' ≤ 0` (the `-k` term dominates because the left wing
  falls at rate at most `qL ≤ 1`); and `k < 0 ≤ k'`, where
  `CALL k ≥ ALm 0 + (-k)(1 - qL) ≥ ALm 0 = AR 0 = CALL 0 ≥ CALL k'` using `atm_wings_meet`
  (whose hypothesis `WR + WL ≠ 0` is discharged in Layer 2 from `WR > 0`, `WL ≥ 0`).
  `CALL_lipschitz` is the same case split with the other side of the sandwich, and
  `PUT_monotone` follows from `CALL_lipschitz` plus parity (`PUT k = CALL k + k`).
* §5 witness: with `a = γ = 1`, `B = 1`, `ibeta = id`, `tail s m = s²/(s+m)` and
  `kern s v = (1 + v/s)^(-2 : ℝ)`; the sandwich is that `1/((s+m)(s+m'))` lies between
  `1/(s+m')²` and `1/(s+m)²` for `0 ≤ m ≤ m'`.
